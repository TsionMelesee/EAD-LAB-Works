# Tutor Connect

Tutor Connect is a web application designed to connect university students with qualified tutors. Tutors can submit their qualifications for approval, and once verified, they can offer tutoring sessions. Students can search for tutors, rate them, and book sessions.

## Features

### For Tutors
- Submit qualification documents for verification
- Receive approval or rejection via email
- Offer tutoring sessions once approved

### For Students
- Search for tutors based on subjects and ratings
- Rate and review tutors
- Book tutoring sessions
- accept tutoring booking approval notification

### For Admin
-review and accept or reject tutor application
